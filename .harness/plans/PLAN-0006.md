# PLAN-0006: Distribution is a tested artifact

Everything the harness delivers to a downstream project — the agent policy,
schemas, verification script, and runtime — is currently reachable only from a
source checkout, and the policy text a generated project receives depends on
how `init` was invoked. This plan makes the distribution a single package
asset set, generated projects a smoke-tested artifact, and CI the thing that
notices when either regresses.
