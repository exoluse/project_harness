# PLAN-0005: Make routine progress reachable from the user's prompt alone

`USER_DIRECTED` mode removes the approval ceremony but not the record
bookkeeping. Reaching a startable TASK from `init` currently needs six manual
record edits, four of which have no command at all: activating a PLAN, setting
`state.current_plan`, linking a TASK into its PLAN, and mirroring
`approval_subject` refs into `approval_dependencies`.

This plan closes that gap so an agent driven only by the user's prompt can
reach a passing `gate task` using commands, never hand-edited front matter.
