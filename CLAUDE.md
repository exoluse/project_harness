# Claude Code Adapter

Follow [AGENTS.md](AGENTS.md) as the governing policy. Read it and this adapter
once per session; a current supplied/read copy counts. Inspect Git status and
only the notes relevant to the user's outcome, stage and existing decisions.

A clear implementation request can supply its scope decision under
[authority and decisions](AGENTS.md#authority-and-decisions). Preserve the
requested stopping point, other writers' work and high-risk/external controls.

New management documents use Markdown. Independent items own exact `<ID>.md`
files in project-chosen folders under [identity rules](AGENTS.md#item-identity-and-trace)
and [required-name exceptions](AGENTS.md#required-name-markdown-files).
Use the shared [plan/task, directory and allocation basis](docs/COLLABORATION.md#collaboration-basis).

Reuse applicable context, allocations and checks under
[efficiency guidance](docs/CONTEXT_EFFICIENCY.md); consult linked detail when
relevant, without rereading unchanged policy. The bundled CLI is optional.
This adapter summarizes the shared policy; all its requirements remain binding.
